RazerMate v2 · 配置驱动版 使用说明
==========================================================

【这是什么】
雷蛇 Basilisk V3 有线版专用。不需要 Synapse，不需要上位机界面，不需要安装。
一个 533 KB 的无窗口后台程序 + 一份 JSON 配置文件，开机自启、常驻约 2 MB 内存，
按当前前台应用自动切换鼠标按键、DPI、回报率和三区灯光。

【三个文件】
  profiles.json                        唯一事实源：所有按键、灯光、匹配规则都在这里
  dist\RazerMate\razermate-headless.exe  后台程序（无界面、无托盘、单实例）
  dist\RazerMate\razerctl.exe            命令行工具：读回设备绑定 / 查看板载槽，排障用

  另外还有 PROFILES_GUIDE.md（给 AI / Agent 看的配置说明）、
  README.md（完整手册与排障）、profiles.schema.json（配置校验契约）。

【现在就怎么用】
  直接编辑本目录下的 profiles.json，保存后约 1 秒自动生效。
  不用重启、不用重新编译、不用打开任何界面。

  ★ 只改这一份：versions\v2-headless\profiles.json
    开机自启命令里已经带 --config 指向它。
    不要去改 %LOCALAPPDATA%\RazerMate\profiles.json —— 那是未指定 --config 时的默认路径，
    当前实例没用它，改那份不会有任何效果。

  配置文件写坏了也不怕：后台会保留上一份有效配置，日志里写明原因，绝不把半截配置写进鼠标。

【当前按键（想改就改 JSON）】
  滚轮左倾 = 粘贴 Ctrl+V      滚轮右倾 = 复制 Ctrl+C
  左键 / 右键 / 上滚 / 下滚 = 保持原生（只是当前配置，不是程序限制，随时可改）
  侧键后退 / 前进、DPI 键、狙击键、滚轮模式键、中键 = 按应用组变化

  四组配置（按前台程序自动切换，优先级大的先命中）：
    global   兜底            1600 DPI / 500 Hz   绿色滚轮+Logo、灯带光谱
    browser  浏览器 / 编辑器 2000 DPI / 1000 Hz  蓝色，后退=关标签、前进=新标签、狙击键=音量+
    kicad    KiCad           1200 DPI / 500 Hz   橙色，后退=保存、前进=另存为、狙击键=撤销
    game     cs2 / LOL / Steam 800 DPI / 1000 Hz 三区波浪

【常用命令】
  在 v2-headless 目录下打开命令行，设：
    set H=dist\RazerMate\razermate-headless.exe
    set CFG=%CD%\profiles.json

    %H% --validate --config "%CFG%"      校验配置（改完 JSON 建议先跑一次）
    %H% --status   --config "%CFG%"      看当前生效的配置路径、选中组、自启状态
    %H% --once     --config "%CFG%"      立刻重新下发一次
    %H% --apply kicad --config "%CFG%"   强制套用某一组
    %H% --install  --config "%CFG%"      写/重写开机自启（必须带 --config）
    %H% --uninstall                      取消开机自启
    %H% --help                           看全部命令

  读回某个键当前实际绑定：
    dist\RazerMate\razerctl.exe binding tiltleft --slot 0

  日志：%LOCALAPPDATA%\RazerMate\headless.log（超过 512 KB 自动裁半）

【出问题先看这里】
  改了 JSON 没反应  → 确认改的是上面★那份；跑 --status 看路径；看日志有没有
                      「配置已热更新」或「配置写坏」
  复制粘贴失效      → 多半是按了鼠标底部 Profile 键切槽，或断电/休眠，p0 被覆盖。
                      跑 --once 立即恢复。想全自动恢复，把 service.reapply_interval_ms
                      从 0 改成 5000（每 5 秒兜底重下发）
  后台没在跑        → 任务管理器找 razermate-headless；跑 --install --config 重写自启
  某组没生效        → 看 --status 的「选中组」；match.exe 要带 .exe 且小写

【必须知道的边界】
  · 所有改动只写 p0（RAM 工作层），绝不读写、切换、擦除鼠标里 5 个板载配置槽。
    这也是配置里 profile 键一律写 off 的原因。
  · p0 断电 / 切槽 / 休眠会丢，后台会重下发；拔掉鼠标再插回也能恢复。
  · 多步宏需要写设备 Flash，默认关闭；当前三个宏都是单步组合键，零 Flash 写入。
  · 只支持 Basilisk V3 有线版（VID 1532 / PID 0099）。

【资源占用实测】
  私有内存 2.13 MB、工作集 10.13 MB（含系统共享 DLL）、1 线程、146 句柄、
  运行 3 分钟累计 CPU 0.16 秒。任务管理器默认「内存」列显示约 2 MB 属正常。
