RazerMate 0.1.0 — 雷蛇巴塞利斯蛇 V3 有线版专用控制程序
==========================================================

【这是什么】
只针对 VID_1532 / PID_0099 的 Basilisk V3 有线版，不依赖雷蛇 Synapse，
不需要安装，解压即用。所有设置写进鼠标自身的板载 Flash，程序关掉后依然生效。

【三个文件】
razermate.exe          控制面板（图形界面，中文）
razermate-agent.exe    后台服务（托盘常驻，按前台程序自动切换板载槽）
razerctl.exe           命令行工具（排障 / 自检 / 批量操作）

【两种模式】
模式一 · 纯净退出（默认）
  直接打开 razermate.exe 改按键、灯效、DPI、回报率、宏、板载槽。
  关掉窗口 = 全部退出，不留任何进程、不写开机启动项。
  只能用鼠标底部的 Profile 键切换 5 组板载槽。

模式二 · 后台服务
  在「自动切换」页点「启动服务」，或直接运行 razermate-agent.exe。
  关掉控制面板后，后台服务留在托盘，按当前前台程序自动切槽。
  内存占用约 2.4 MB（私有工作集），不加载界面。
  在「概览」页底部可开启「开机启动」；在「自动切换」页可停止服务。

【离线模式 / 在线模式】—— 在窗口右上角「运行模式」处分段切换，一眼可见
离线模式（默认）
  只用鼠标板载的 5 个槽，宏由鼠标固件执行，不装任何软件也能用。
  此时左侧没有「自动切换」入口——自动切宏、无限槽、扩展灯效都是在线模式的功能。

在线模式（虚拟槽，底层仍是 normal 0）
  点右上角「运行模式」里的「在线」，左侧出现「在线模式 / 自动切换」入口：
  1. 进「自动切换」页，点「新建」创建一个虚拟槽；
  2. 填名称、要匹配的程序名（多个用逗号分隔，如 chrome.exe,code.exe）；
  3. 每槽可独立设灯效：灯带 / Logo / 滚轮三区，各有静态（含颜色）/ 光谱 / 波浪与亮度；
     另可设 DPI、回报率；
  4. 点「保存」，再点「立即套用」即可看到效果；
  5. 后台服务运行时，切到匹配的程序会自动套用整套配置。
  虚拟槽写入鼠标的临时工作层（p0），零 Flash 磨损，切槽或断电即恢复板载内容。
  完整配置在 %LOCALAPPDATA%\RazerMate\vslots\，可直接手改。
  命令行：razermate-agent.exe --vslots 查看，--vsapply v1 手动套用。

注意区分：右上角「运行模式」是程序行为（离线/在线）；设备卡与状态栏显示的
「设备层 · 普通 (0) / 驱动 (3)」是 HID 协议层状态，写 DPI 时会短暂切到驱动层。

  内存说明：在线模式的后台占用是优化重点。常驻内存的只有虚拟槽索引，
  100 个虚拟槽实测仅多占约 32 KB；完整配置按需读取、用完即弃。
  前台界面只在设置时使用，占用大一些无妨。

【灯光说明】
板载可持久化的只有三种：静态色、光谱循环、波浪 —— 写在鼠标 Flash 里。
「灯带预览」的彩虹 / 渐变 / 流动是运行时效果，不写 Flash，切槽或断电即恢复；
预览前会记下原灯效，点「还原」即可恢复（关掉程序后依然能还原）。

【宏的三种触发方式】
在「自定义」页的「按键映射」分节点一下鼠标示意图上的物理键，可以把宏绑成：
  播放宏       按一次播放一次（可指定重复次数）
  按住播放宏   按住期间循环播放，松开即停
  开关播放宏   点一次开始循环，再点一次停止
三种方式都写进按键绑定、断电不丢；物理触发已在本机实机验收。
命令行等价写法：
  razerctl.exe bind dpi macrohold:0x0101
  razerctl.exe bind forward macrotoggle:0x0102
（宏 ID 换成自己 Flash 里真实存在的 ID，可用 macro list / macro scan 查）

【按键参数不用手填】
「自定义」页的「按键映射」分节左边是一只鼠标俯视图，点图上的按键（左键 / 右键 /
滚轮上 / 中键 / 滚轮下 / 滚轮左右倾 / DPI / 后退 / 前进 / 狙击 / Profile / 滚轮模式）
就能切换要改的键，
右边随即显示它当前的动作；改完点「写入」才下发，点「取消」收起编辑区。
参数区按类型给出可直接点的选项：
  鼠标键   左 / 右 / 中 / 后退 / 前进 / 滚轮上下 / 左右倾（9 个）
  组合键   复制 / 粘贴 / 剪切 / 全选 / 保存 / 撤销 / 重做 / Alt+Tab，
           或点「录入组合键」后直接按键盘（支持 Ctrl / Shift / Alt / Win）
  DPI 动作 提高 / 降低 / 循环
  媒体键   播放暂停 / 上下曲 / 停止 / 静音 / 音量 ±
  宏       列出 Flash 里已有的宏点选；播放宏另选 1 / 2 / 3 次
极少数预设没覆盖的键，可点「手动输入（高级）」展开输入框自行填写。

【配置在哪】
%LOCALAPPDATA%\RazerMate\
  rules.conf        自动切换规则（程序名 = 板载槽）
  macros.conf       已知宏 ID 登记表
  agent.token       本地管道令牌（自动生成，勿外传）
  agent.log         后台服务日志
  backups\          配置快照（纯文本，可 diff）
  led-preview.bak   灯带预览前的灯效备份

【自检】
  razerctl.exe info              看设备是否在线
  razerctl.exe selftest          8 项读回校验（会临时改值再还原）
  razerctl.exe bench-led 60      逐颗灯刷新帧率
  razerctl.exe led preview rainbow / restore    灯带预览与还原
  razerctl.exe backup save       导出配置快照
  razerctl.exe backup restore    从 latest.txt 恢复
  razerctl.exe macro scan        扫描 Flash 里已有的宏

【卸载 / 干净退出】
1. 在「自动切换」页点「停止服务」（或 razermate-agent.exe --quit）。
2. 在「概览」页底部「设置」分节关闭开机启动（若开过）。
3. 删除本目录和 %LOCALAPPDATA%\RazerMate\ 即可。
鼠标板载设置不会因此丢失。

【注意】
- 改 DPI 会短暂切到 driver mode（约 1 秒，期间板载宏不响应），程序会自动
  切回并还原生效槽。
- 写入操作一律「读回校验，不一致自动回滚」；宏覆写会先备份旧内容，
  写失败自动还原。
- 覆写已存在的宏 ID 时设备要求先删除，程序已自动处理。
