# RazerMate 配置参考

[`配置指南.md`](配置指南.md) 写的是「现在配置成什么样」。
这份文件写的是「怎么改」——动作串语法、字段含义、命令行、以及几个必须知道的边界。

---

## 一、动作串写法

| 写法 | 说明 |
| --- | --- |
| `native` | 保持该键出厂功能（具体是什么由 `device.buttons[键].native` 决定） |
| `mouse:left` / `mouse:back` | 鼠标基础功能 |
| `mouseext:tiltleft` | 鼠标扩展功能（固件 fn=14 那一类） |
| `key:ctrl+v` | 任意组合键；主键也可以用 `0x` 十六进制 HID usage |
| `macro:close_tab` | 播放宏（单击触发） |
| `macrohold:xxx` | 按住时循环播放 |
| `macrotoggle:xxx` | 按一下开始、再按一下停止 |
| `media:volup` / `media:0x00e9` | 媒体键 |
| `dpi:up` / `dpi:down` / `dpi:cycle` | 绑成 DPI 档位动作 |
| `wheelmode` | 切换滚轮阻尼 |
| `off` | 禁用这个键 |
| `profile:next` / `double` / `hypershift` | 其它固件功能 |
| `raw:<fn>,<size>,<d0..d4>` | 逃生舱：直接写原始绑定字节，固件新增功能不用重编译 |

## 二、可用值

| 项 | 范围 |
| --- | --- |
| DPI | 100–26000 |
| 回报率 | 125 / 500 / 1000 Hz |
| 亮度 | 0–255 |
| 灯效 | `static`（需 `rgb`）· `spectrum` · `wave`（可给 `mode`、`speed`） |
| 灯区 | `wheel` 滚轮（region 1）· `logo`（4）· `strip` 灯带（10） |
| 绑定层 | `normal` / `hypershift` |
| 宏触发 | `once` / `hold` / `toggle` |

## 三、匹配字段

| 字段 | 含义 |
| --- | --- |
| `match.exe` | 前台进程名，带 `.exe`，小写比较 |
| `match.title_contains` | 窗口标题包含任一子串 |
| `match.path_contains` | 进程完整路径包含（可选维度） |
| `priority` | 越大越优先，同时命中取最大 |
| `service.fallback` | 都没命中时用哪套，当前 `global` |

轮询间隔 800 ms，所以切程序后最多 0.8 秒生效。
UWP / 商店应用的前台进程是 `ApplicationFrameHost.exe`，光靠 `exe` 匹配不到，得用 `title_contains` 补。

## 四、常见改动

配置指南表里的「键」就是 JSON 的 `base.bindings.<键>`，「动作」就是它的 `action` 值；
某个配置组的改动对应 `profiles[].overrides.bindings.<键>.action`。

| 想做什么 | 改哪里 |
| --- | --- |
| 换某个键的功能 | `base.bindings.<键>.action`，或某组的 `overrides.bindings.<键>.action` |
| 交换复制 / 粘贴 | 对调 `tiltleft.action` 与 `tiltright.action` |
| 新增一个应用专用配置 | `profiles` 里加一项：`id` / `scope: "app"` / `priority` / `match.exe`，`overrides` 只写要变的键 |
| 关掉某个灯区 | 该区 `brightness: 0` |
| 换鼠标型号 | 改 `device.buttons` 的 ID 与 `native`、`device.led_regions` 编号 |

`_` 开头和不认识的字段会被忽略，可以安全地加注释或试验字段。

## 五、命令行

设 `H` = `RazerMate\razermate-headless.exe`，`CFG` = `RazerMate\profiles.json` 的绝对路径。

| 命令 | 作用 |
| --- | --- |
| `H --validate --config <CFG>` | 只校验配置，不碰设备 |
| `H --status --config <CFG>` | 看生效路径 / 当前前台 / 选中组 / 自启状态 |
| `H --once --config <CFG>` | 立即重新下发一次 |
| `H --apply kicad --config <CFG>` | 强制套用某组 |
| `H --install --config <CFG>` | 写开机自启（必须带 `--config`） |
| `H --uninstall` | 删开机自启 |
| `H --run --config <CFG>` | 常驻运行 |
| `razerctl.exe binding tiltleft --slot 0` | 读回某个键在设备上的实际绑定 |

日志：`%LOCALAPPDATA%\RazerMate\headless.log`

## 六、必须知道的边界

**只写 p0（RAM 工作层）。** 不碰板载 Flash，所以不磨损设备、不占用 5 个硬件槽。
代价是 p0 易失：休眠、按鼠标底部 Profile 键、断电都会让它回落到板载配置。
恢复方式：切一次前台程序、改一次 `profiles.json`、跑一次 `--once`，或者重启后台。

**DPI / 回报率刻意不下发。** 写这两项必须先切 driver mode 再切回，每次都会还原板载槽并覆盖整个 p0，
形成「写 DPI → 切模式 → p0 被覆盖 → 再写」的死循环，表现是滚轮阻尼反复切换、灯效反复重刷、
按键读回变回出厂值，而且 DPI 实际也留不住。

所以 `sensor._preference` 只作记录。**不要**把它改回裸 `dpi` / `polling`，也**不要**开启定时重下发
（`reapply_interval_ms` 保持 0）。

**只支持 Basilisk V3 有线版**（`1532:0099`），换别的型号需要先补设备档案。
