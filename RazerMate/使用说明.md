# RazerMate 使用说明

适用设备：Razer Basilisk V3（USB ID `1532:0099`）。别的型号不会工作。

---

## 一、启动与关闭

**双击 `start.cmd`** → 程序会列出自检信息，问你 `确认启动？[Y=启动 / N=取消]`，按 `Y` 回车即可。
启动成功后窗口会自己关掉，程序在后台运行，**没有托盘图标、没有窗口**。

**双击 `stop.cmd`** → 会先列出当前运行的实例，再问你 `确认关闭？[Y=关闭 / N=取消]`。

两个脚本都会在动作执行完**重新查一次进程表**，按真实结果告诉你成功还是失败，不会只打印一句「已完成」。

| 脚本提示 | 含义 |
| --- | --- |
| `[成功] RazerMate 后台已启动` | 进程确实起来了 |
| `[失败] 进程没有起来，请查看日志` | 没起来，按提示的路径看日志 |
| `RazerMate 后台已经在运行` | 已有实例，不会重复启动 |
| `RazerMate 后台当前没有运行` | 确实没在跑，不需要关闭 |

程序默认开机自启（注册表 `HKCU\...\Run` 里的 `RazerMateHeadless`），所以重启电脑后会自动运行，一般不用手动点。

---

## 二、它到底做了什么

按当前**前台窗口是哪个程序**，自动把一整套配置写进鼠标：

- `chrome.exe` → 浏览器组（蓝灯，后退=关标签、前进=新标签）
- `kicad.exe` → 画板组（橙灯，后退=保存、前进=另存为、狙击键=撤销）
- 游戏 → 三区波浪灯
- 其它 → 全局兜底组（绿灯带光谱）

配置只写进鼠标的 **Profile 0 临时层（p0）**，不写 Flash。p0 是固件维护的 RAM 工作副本，写它不磨损设备、不占用你板载的 5 个配置槽。

**代价**：p0 是易失的。休眠、按鼠标底部的物理 Profile 键、断电，都会让它回落到板载配置。恢复方式：再启动一次程序，或者改一次 `profiles.json`（触发热更新），或者运行 `razermate-headless.exe --once --config profiles.json`。

---

## 三、改配置

编辑 `profiles.json`，**保存后约 1 秒自动生效**，不用重启、不用重新编译。改坏了也不怕——程序发现 JSON 无效会保留上一份有效配置，不会把半截配置写进设备。

怎么改看 [`配置指南.md`](配置指南.md)，里面有：

- 13 个按键的 ID 对照表
- 可用动作串（`macro:`、`dpi:`、`media:`、`key:` 等）
- 每个配置组的匹配规则（`exe` / `title_contains` / `path_contains`，三者是**或**关系）
- 灯效参数（`static` / `spectrum` / `wave` / `breathing` 等）

⚠️ **DPI 和回报率不在软件控制范围内**，这是刻意设计，不是没做完。
写这两项必须先切 driver mode 再切回，每次都会还原板载槽并覆盖整个 p0，导致设备反复重置（滚轮阻尼和灯效持续抖动），而且 DPI 实际也留不住。
请用鼠标顶部的 DPI 键或雷云设置。`profiles.json` 的 `sensor._preference` 只是**记录**各组的偏好值，不会下发。

## 四、日志与排查

日志：`%LOCALAPPDATA%\RazerMate\headless.log`

正常运行时每次切换都会记一行：

```
08:08:16  组=global 前台=workbuddy.exe | 已套用「全局兜底」
```

| 现象 | 原因 / 处理 |
| --- | --- |
| 灯不亮、按键没变化 | 先确认 `start.cmd` 报的是「成功」；再确认鼠标是 Basilisk V3 |
| 休眠唤醒后失效 | p0 被固件还原了，正常现象，重新启动或跑一次 `--once` |
| 换前台程序没反应 | 看日志有没有新的 `组=` 行；没有就是进程没在跑 |
| 脚本一闪而过 | 右键「以管理员身份运行」一般不需要；若仍闪退，从命令行窗口运行看报错 |
| 提示配置无效 | `profiles.json` 语法错了，程序会保留上一份配置继续跑 |

命令行自检（在 `RazerMate` 文件夹里打开 cmd）：

```
razermate-headless.exe --validate --config profiles.json    # 只校验配置，不碰设备
razermate-headless.exe --status   --config profiles.json    # 看当前选中组、自启状态
razermate-headless.exe --once     --config profiles.json    # 手动下发一次
```

---

## 五、卸载

```
razermate-headless.exe --uninstall    # 只删开机自启
```

然后把整个 `RazerMate` 文件夹删掉即可。程序不在系统目录留任何东西，唯一的痕迹是
`%LOCALAPPDATA%\RazerMate\`（日志和配置缓存），可以一并删除。

鼠标本身不受影响——所有改动都在 p0，断电即消失。
